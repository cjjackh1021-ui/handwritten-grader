# 默认评分标准

总分100分，各维度及分值如下（评分时从宽把握，亮点可多给分）：

1. 实验目的与原理阐述（18分）：能够基本阐述实验背景、相关算法/方法的原理及优点即可给满分；表述略有不足扣1-2分。
2. 系统需求分析与方案设计（22分）：需求分析基本全面，模块划分合理，流程图基本清晰即可给满分；小瑕疵扣1-3分。
3. 模块设计与关键代码（25分）：各模块设计思路基本清晰，代码片段基本合理、有注释即可给满分；逻辑基本完整扣1-3分。
4. 系统集成与测试（20分）：测试内容包含基本项（数据采集、算法对比、数据库、功能演示等）即可给满分；缺少部分测试项酌情扣2-5分，但若其他方面优秀可不扣。
5. 实验总结与创新点（15分）：总结基本全面，能提及至少一个创新点即可给满分；展望合理即可，不要求非常深入。

基础分（报告规范与格式）（0分，作为附加）：不单独扣分，报告结构基本完整、语言基本通顺即可，明显格式问题最多扣2分，但总分仍可超过95。

加分项（直接并入各维度，不单独设上限）：
- 有明显工程实践亮点（如鲁棒性测试、多场景适应、详细日志等）可在对应维度加2-5分，总分不超过100。
- 内容非常丰富、超出要求可在总结创新点维度加3-5分。

扣分项（尽量少扣）：
- 缺少关键图表（如流程图、测试截图）每处扣1-2分。
- 有明显事实错误每处扣1分。
- 抄袭或雷同仍直接0分（不可仁慈）。

总体原则：只要学生认真完成，态度端正，内容无明显错误，尽量给80分以上；表现良好即可85-90分；非常优秀可给90-95分。
